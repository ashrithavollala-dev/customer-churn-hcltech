### last_csat_score handling

- Raw CSAT missing: 45 rows; out of the 1-5 range (e.g. 0, 7, 9): 4 rows.
- Final values for those rows: {4.0: 49}
- Raw median CSAT (all rows): 4.0; train-period median: 4.0
- Conclusion: missing and invalid CSAT were replaced by 4.0. The median appears to have been taken over the full raw file rather than train only; because the train-only median is the same value (4.0) this has no practical effect, but it cannot be confirmed from the code that produced the files.
- No missing-CSAT indicator column exists, so the model cannot tell an imputed 4.0 from a real 4.0.
